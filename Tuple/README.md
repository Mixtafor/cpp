# Tuple

В этой задаче вам предлагается поупражняться в использовании **variadic templates**, а также `type_traits` с использованием **SFINAE** и/или концептов.

Нужно написать шаблонный класс с переменным количеством аргументов — **Tuple** (кортеж), обобщение класса `std::pair`, простенький аналог `std::tuple` из C++11.

## Требования к классу Tuple

### Конструкторы

1. **Конструктор по умолчанию**  
   - Все элементы кортежа инициализируются значениями по умолчанию.  
   - Должен участвовать в перегрузке тогда и только тогда, когда `std::is_default_constructible<Ti>::value` верно для всех `i`.  
   - Должен быть `explicit` тогда и только тогда, когда `Ti` не является `copy-list-initializable` из `{}` для какого-либо `i`.

2. **Конструктор из набора аргументов соответствующих типов** (аналог конструктора №2 на [cppreference](https://en.cppreference.com/w/cpp/utility/tuple/tuple)).  
   - Должен участвовать в перегрузке, только если `std::is_copy_constructible<Ti>::value` верно для всех `i`.  
   - Должен быть `explicit`, если `std::is_convertible<const Ti&, Ti>::value` неверно хотя бы для одного `i`.

3. **Конструктор от универсального набора аргументов `UTypes&&... args`** (аналог конструктора №3).  
   - Участвует в перегрузке, только если:  
     - размеры пакетов аргументов совпадают и больше 1;  
     - `std::is_constructible<Ti, Ui>::value` верно для всех `i`.  
   - Должен быть `explicit`, если `std::is_convertible<Ti, Ui>::value` неверно хотя бы для одного `i`.

4. **Конструкторы от `Tuple<UTypes...> other`** (версии (5) и (6)).  
   - Версия от `const Tuple<UTypes...>&` и версия от `Tuple<UTypes...>&&`.  
   - Каждый элемент `Tuple` инициализируется выражением `get<i>(FWD(other))`, где `FWD(other)` = `std::forward<decltype(other)>(other)`.  

   Участвуют в перегрузке, только если выполнены условия:  
   - размеры пакетов `Types` и `UTypes` совпадают;  
   - `std::is_constructible_v<Ti, decltype(get<i>(FWD(other)))>` верно для всех `i`;  
   - либо размер пакета `Types != 1`, либо `std::is_convertible_v<decltype(other), T>`, `std::is_constructible_v<T, decltype(other)>` и `std::is_same_v<T, U>` все равны `false`.  

   Эти конструкторы должны быть `explicit`, если `std::is_convertible_v<decltype(std::get<i>(FWD(other))), Ti>` неверно хотя бы для одного `i`.

5. **Конструкторы от `std::pair<T1, T2>`**  
   - Версия от `const std::pair<T1, T2>&` и от `std::pair<T1, T2>&&`.  
   - Создают `Tuple<T1, T2>`.  
   - Для корректной работы этих конструкторов, вероятно, понадобится написать **template deduction guides**.

6. **Копирование и перемещение Tuple**  
   - Конструктор копирования должен кидать CE, если `std::is_copy_constructible<Ti>::value` неверно для какого-либо `i`.  
   - Конструктор перемещения не должен участвовать в перегрузке, если `std::is_move_constructible<Ti>::value` неверно для какого-либо `i`.

### Операторы присваивания

- **Копирующее присваивание**  
  - CE, если `std::is_copy_assignable<Ti>::value` неверно хотя бы для одного `i`.

- **Перемещающее присваивание**  
  - Присваивает каждому элементу выражение `std::forward<Ti>(get<i>(other))`.  
  - Участвует в перегрузке только если `std::is_move_assignable<Ti>::value` верно для всех `i`.

- **Присваивание от `const Tuple<UTypes...>& other`**  
  - Участвует в перегрузке, только если размеры пакетов совпадают и  
    `std::is_assignable<Ti&, const Ui&>::value` верно для всех `i`.

- **Присваивание от `Tuple<UTypes...>&& other`**  
  - Участвует в перегрузке, только если размеры пакетов совпадают и  
    `std::is_assignable<Ti&, Ui>::value` верно для всех `i`.

- **Присваивания от пары**  
  - От `const std::pair<T1, T2>&` и от `std::pair<T1, T2>&&`.

> Конструкторы (4), (7), (8), (11)-(12), а также (15)-(28) со страницы cppreference поддерживать **необязательно**.  
> Также необязательно поддерживать операторы присваивания (2), (4), (6), (8), (10), (12)-(14).

## Функции вне класса

Необходимо реализовать функции, аналогичные стандартным:

- **`makeTuple`**, **`tie`**, **`forwardAsTuple`** — создают новый `Tuple`, аналогично `std::make_tuple`, `std::tie`, `std::forward_as_tuple`.

- **`get<size_t Index>`**  
  Принимает `Tuple` и возвращает ссылку на `Index`-й элемент кортежа.  
  Ссылка должна быть того же вида (lvalue/rvalue, const), что и у принятый `Tuple`.

- **`get<T>`**  
  Принимает `Tuple` и возвращает ссылку на элемент кортежа типа `T`.  
  Ссылка должна быть того же вида (lvalue, const lvalue, rvalue), что и у `Tuple`.  
  - Если в `Tuple` нет элемента типа `T` или таких элементов несколько → CE.

- **`tupleCat`**  
  Возвращает кортеж, являющийся конкатенацией нескольких кортежей.  
  - Если исходный кортеж был lvalue → элементы копируются.  
  - Если rvalue → элементы перемещаются.  
  - Каждый элемент должен копироваться или перемещаться **не более одного раза**.
